# 아트링크 1.11.7 수정 내역과 배포 전 확인

2026-09-23. 검토용 브랜치: `codex/artlink-1.11.7-safety`.
앱 버전 1.11.7, iOS 빌드 84, Android versionCode 86.

## 수정한 사용자 문제

- 로그아웃하거나 다른 계정으로 로그인할 때 노트·프로필·포트폴리오·초안·연습 기록이 섞이지 않도록 계정별로 저장한다. 진행 중인 조회와 저장도 계정 경계를 넘지 않는다.
- 새 게스트의 기록은 가입 계정으로 한 번 이관한다. 소유자를 확인할 수 없는 구버전 자료는 원본을 보존하고 자동 합치지 않으며 복구 안내를 표시한다.
- 실제 저장이 실패하면 성공 표시를 하지 않는다. 노트 삭제 실패는 다시 시도하고 삭제한 기록이 동기화로 되살아나는 것을 막는다.
- 녹음·사진은 앱의 영구 저장 폴더로 복사한 뒤 저장한다. 실패 시 원본과 작성 내용을 유지한다. 2인 대사 녹음은 이탈 전에 저장 여부를 확인한다.
- 프로필 사진 전체 목록·대표 순서를 유지하고 파일 이름 충돌을 피한다.
- 오디오 전사가 실패하면 오디오를 빼고 AI 분석을 진행하지 않는다. 스트림의 명시적 완료를 확인해야 결과를 성공으로 처리한다.
- AI 생성 후 로컬 저장만 실패하면 생성 결과를 화면에 유지한다. ‘저장 다시 시도’는 AI 요청이나 이용 횟수 차감을 다시 하지 않는다. 앱 강제 종료까지 보장하는 서버 결과 보관은 별도 과제다.
- 신규 학습 자료 수집은 중단한다. 운영 통계에 자유 입력 제목·태그·피드백 본문을 보내지 않는다. 기존 device_id 통계는 남으므로 완전한 익명화를 구현했다고 표현하지 않는다.
- 동의 철회는 로그인 계정 미디어 보관함의 삭제 완료를 확인한 경우에만 해당 범위의 완료를 안내한다. 실패 후 재시도 버튼을 제공한다.

## 자동 검증

- 앱 Jest 전체: 46개 묶음, 538개 테스트 통과.
- iOS·Android Expo/Hermes 번들 생성 통과.
- 서버 테스트와 변경 내역은 서버 저장소 `docs/1.11.7-server-handoff.md` 참조.
- 실제 iPhone/Android 기기의 녹음·네이티브 뒤로가기·계정 전환은 별도 점검이 필요하다.

## 배포 전에 반드시 해결할 것

1. **서버를 먼저 반영해야 한다.** 앱은 `/api/ai-analyze?stream=1&protocol=events`의 NDJSON 완료 이벤트를 요구한다. 서버 변경 없이 이 앱만 배포하면 글 AI 분석이 실패한다. 서버는 기존 plain 요청도 지원한다.
2. **운영 DB SQL은 아직 적용하지 않았다.** `migrations/2026-09-23-note-practice-meta.sql`은 연습 연결 복원용 컬럼과 삭제 부활 방지 트리거다. 사전 검토·스테이징 검증 후 운영 적용이 필요하다. 구버전 혼용·동시 동기화 보호는 트리거 적용까지 완료되지 않는다.
3. **실제 회원 탈퇴는 미완성이다.** 기존의 기기 저장소 초기화를 ‘계정 삭제 완료’로 보이게 하던 동작을 막고 미완료 안내로 바꿨다. 인증 계정·프로필·기록·소유 미디어까지 처리하는 서버 삭제 흐름을 완성하고 실패·재시도를 검증하기 전 스토어 제출하지 않는다.
4. **프로필 공개 OFF의 서버 저장과 동시 업로드 충돌**은 이번 수정에 포함되지 않았다. 앱 재실행·다른 기기·늦은 업로드에서도 비공개가 유지되는지 해결해야 한다.
5. **소유자 불명 구버전 기록의 복구 정책**을 정해야 한다. 자료는 지우지 않았지만 자동 표시하지 않는 사용자가 생길 수 있다. 본인 확인 없는 현재 계정 합치기는 금지한다.
6. **기존 학습 텍스트·게스트 미디어는 삭제하지 않았다.** 현재 철회 성공 범위에 포함되지 않으며, 식별·보존·삭제 정책은 별도로 정해야 한다. 원본 미디어의 다른 기기 백업도 완료 범위가 아니다.

## 빌드와 후속 작업

`review-production` 프로필은 스토어 서명 파일을 만들되 `codex-review-1-11-7` 업데이트 채널을 쓴다. 이 파일은 검토용이며 자동 제출하지 않는다. 출시할 최종 소스와 버전 번호를 확정한 후 새 빌드를 권장한다.

Claude에서 이어서 작업할 때 원래 main 폴더에 이 변경을 수동 복사하지 말고 두 저장소의 `codex/artlink-1.11.7-safety` 브랜치와 이 문서를 먼저 확인한다. 우선 실제 회원 탈퇴와 공개 OFF를 완성하고, 위 순서대로 서버·DB·실기기 검증을 거친 뒤 스토어 제출을 결정한다. 기존 원본 작업 폴더의 미커밋 변경은 유지되어 있다.
